# BURO PAY — Studio edition

Второй самостоятельный вариант дизайна. Контрастная редакционная типографика, холодный оливковый фон, графитовый калькулятор и лаймовый акцент.

## Установка

```bash
npm install
npm run dev
```

Сборка: `npm run build`, результат в `dist/`.

## Настройка

- Telegram менеджера: константа `TELEGRAM` в `src/App.jsx`.
- Валюты: `CURRENCIES`; базовые демонстрационные курсы: `INITIAL_RATES`.
- Фиатные курсы обновляются с внешнего публичного API при наличии доступа.
- Криптовалютные курсы демонстрационные; для реального обмена подключите актуальный источник или согласуйте курс с менеджером.

При публикации на Cloudflare Pages: Build command `npm run build`; output directory `dist`.
